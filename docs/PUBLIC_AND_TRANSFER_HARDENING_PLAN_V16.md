Status: **AUTHORIZED LOCAL IMPLEMENTATION / NO PUBLICATION / NO STUDY**

Baseline: `4d2e11ceb26b36fd7428dc7de963c135802a8dea`

This phase preserves the exact v16 owner-review checkpoint and improves four
bounded surfaces without reopening the locked thesis:

1. the applied companion's Stage 0, permission, reference-integrity, sparse-use,
   and memory contracts;
2. a public presentation mode generated from the same canonical sources as the
   owner-review site;
3. one deterministic teaching reveal that replaces, rather than accumulates on,
   an existing static example; and
4. a current targeted adjacent-work route plus an unrun decision memo for a
   future narrow empirical wedge.

The phase does not authorize a merge to `main`, deployment, publication,
outreach, participant or model study, provider selection, dataset acquisition,
preregistration, or spend.

The human thesis, six-family map, ordinary-work escape, permanent Echo split,
human-authority boundary, and no-results boundary remain fixed. Technical
repairs must not migrate protocol density into the essay, 90-second version,
mentor note, or public opening.

The current checkpoint is an owner-reviewable design/governance synthesis. It
is not a validated method, a newly invented technical layer, a novel six-part
taxonomy, or evidence that AI answers improve.

## Acceptance checkpoints

### Applied integrity

- Stage 0 occurs before `FRAME` in the copied prompt and terminates ordinary
  work.
- A valid ordinary record cannot contain layered evidence, route, stop,
  outcome, or learning-event fields.
- `AUTHORIZED`, `UNKNOWN`, `NOT_AUTHORIZED`, and `REVOKED` remain distinct.
- Baseline, comparison, disconfirmation, selected influence, and memory claims
  resolve to the evidence/records they name.
- Unknown, absent, or revoked material cannot become selected influence.
- At least one layered example uses only the material families it needs.
- Memory correction appends and links; it never silently overwrites.

### Public presentation

- Review and public builds consume the same canonical content and route IDs.
- No public-only thesis or unsupported claim exists.
- At 390x844 and 1280x720, actual short-version prose is visible in the initial
  public Read viewport.
- Public mode contains no owner-review, package-status, source-machine, or
  repository-manifest chrome in the ordinary reading flow.
- Human authority, proportionality, Echo no-results, and planning-versus-event
  boundaries remain visible where material.
- The teaching reveal is deterministic, static-equivalent, printable,
  keyboard/screen-reader structured, and free of network/model calls, scores,
  observed-result tokens, or automatic action.

### Research and claims

- The 2025–2026 route is explicitly targeted, not systematic or exhaustive.
- Established adjacent mechanisms constrain novelty claims without redefining
  the owner thesis.
- The project is described as a human-governed design/governance synthesis and
  testable agenda, not a validated new mechanism.
- Any receipt-versus-list or observation-boundary design remains unrun and
  records the strongest case against selecting it.
- Echo remains a separate origin-accounting project and cannot define v16.

### Integration and release-candidate boundary

- Locked owner intent, archive, Echo, framework, site, portable-package, and
  owner-manifest checks pass in a clean clone.
- Independent model review is advisory and receives an exact commit.
- Physical keyboard, supported screen reader, real zoom, forced colors, native
  print, hardware touch, owner/mentor comprehension, byline, canonical URL,
  and publication-time link/metadata checks remain explicit human/release
  gates.
- The phase stops at a local owner/public release candidate. Publication,
  deployment, outreach, study execution, and merge remain separately gated.
