## Dependency rules

- Foundation must be committed before any durable subordinate task begins.
- Intent freeze must be committed before manuscript, framework, Echo curation,
  or advisory work begins.
- Site implementation begins only after manuscript and playbook converge and
  the content interface is frozen.
- Generated image work begins only from a written visual-needs list.
- Every subordinate branch has exclusive path ownership and an isolated
  worktree. The primary orchestrator alone integrates.
- A review is not accepted because it is detailed. Every recommendation gets a
  recorded disposition against a governing requirement.

## Release boundary

request. It does not mean publication, deployment, merge, GitHub Release, or an
empirical research release.
