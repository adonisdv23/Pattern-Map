# Targeted prior-measurement matrix

**Status:** targeted and non-exhaustive; source route for claim restraint only.

This matrix records neighboring measurement work so the project does not make
the overbroad claim that retrieval redundancy or dependence has never been
measured. Inclusion here is not a novelty claim, endorsement, or evidence that
EP v1.1's narrower gap exists. Each row needs a future scoped review before it
supports a paper claim.

| Work | What it measures or provides | What it does not establish for EP | Planned use |
| --- | --- | --- | --- |
| Henzinger et al. (WWW 2003) | Near-duplicate prevalence in news-search results and filtering effects | Not typed claim-support provenance in contemporary RAG | Prior prevalence context |
| Groundhog Day (WWW 2013) | Near-duplicate tweets at top-k search ranks | Not source-origin truth or claim support | Prior prevalence context |
| CopyCat (ECIR 2021) | Near-duplicates within/between web collections and top-ranked runs | Not a dependence-aware RAG endpoint | Retrieval redundancy context |
| News Provenance (2020) | Web-scale news text reuse and origin/history reconstruction | Not the EP FC/VOR truth boundary | Provenance-method context |
| NEWS-COPY (ICLR 2023) | Labelled same-original news reproduction clusters | No claim truth, support, independence, FC_cons, or VOR labels | Optional origin-cluster validation only |
| Newswire (NeurIPS 2024) | Detector-derived wire reproduction structure and aggregate cluster metadata | Not complete member/version/claim-support truth for EP endpoints | Aggregate recurrence context only |
| RARE (2026) | Redundancy at the fact level in retrieval benchmarks | Not typed common-origin truth or the F0/F1/F2 intervention | Modern redundancy context |
| Ross et al. (2026) | Duplicate/paraphrased/diverse evidence-set effects in a RAG setting | Does not settle provenance measurement or the EP causal question | Adjacent modern RAG context |
| EvidentialRAG (arXiv:2607.10491v1) | Conflict-preserving fusion over claim-support masses from retrieved chunks | Equation (7) gives `K=0` when copies support the same singleton, so the `lambda K` conflict-transfer term does not respond to same-claim recurrence; §§6.4–7 add provenance/source quality only as future work, not a dependence correction | One mechanism-specific boundary; not a seven-system absence claim |

## Narrow, unproven gap

The only defensible prospective gap statement is conditional:

> A validated instrument for typed, provenance-aware same-origin structure in
> contemporary top-k RAG evidence, linked to claim-support status while
> preserving unknown relations, may be a useful second-paper question.

This is not a finding. It requires a scoped prior-art review, rights and
version verification, labelled-instrument validation, and a claim-support
annotation boundary before any novelty wording is used.
