# Discrimination Layer v15.2 local reader

This directory contains the canonical interactive Essay / Explore / Lab reader
for the v15.2 local owner-review package.

The reader presents a conceptual synthesis and an unrun research program. It
contains no empirical results, is marked `noindex, nofollow`, and is not
published or deployed. The semantic HTML is the canonical accessible reading
surface; `../output/pdf/PATTERN_MAP_V15_2_REVIEW_COMPANION.pdf` is an
explicitly untagged visual/print companion.

## Prerequisite

- Node.js `>=22.13.0`

Use the committed lockfile:

```sh
npm ci
```

## Local development

```sh
npm run dev -- --hostname 127.0.0.1 --port 8773
```

Open `http://127.0.0.1:8773/`. The home route contains cumulative 60-90-second,
about-four-minute, and about-nine-minute stops; `/explore`, `/lab`, and
`/sources` expose progressively more detail. Lab reports protocol status and
open gates only; it is not a results surface.

## Validation

```sh
npm run lint
npm test
```

`npm test` performs a production build and then runs seven rendered-HTML tests.
The suite checks document structure, unique identifiers and fragment targets,
all eleven responsibility records and visible evidence-status labels, the typed
receipt, `UNKNOWN` semantics, F0/F1/F2 and descriptive T1 boundaries, exact
`FC_cons`/VOR/open-gate language, the absence of F3/results claims,
keyboard-returning disclosure controls, route-correct current navigation,
focusable skip targets, local images, local-only metadata, focus styling, and
print/fallback rules.

For a production-mode local check:

```sh
npm run build
npm run start -- --port 8773
```

## Relevant source

- `app/page.tsx` composes the home and essay experience.
- `app/HomeEssay.tsx` owns the three-stop public argument.
- `app/ReferenceRoutes.tsx` owns the Explore, Lab, and Sources routes.
- `app/DeepReceipt.tsx` renders the detailed fictional receipt.
- `app/MicroVisual.tsx` renders the code-native explanatory visuals.
- `app/explore/page.tsx`, `app/lab/page.tsx`, and `app/sources/page.tsx`
  provide the routed detail surfaces.
- `app/content.ts` holds deterministic framework and citation content.
- `app/globals.css` defines responsive, focus, reduced-motion, and print rules.
- `app/Term.tsx` provides the interactive plain-language explanations.
- `app/CollapseControl.tsx` provides keyboard-returning close behavior.
- `app/ReadingNav.tsx` provides the same-page reading path.
- `public/images/` contains the labelled historical v13 map and worked-example
  illustration.
- `tests/rendered-html.test.mjs` is the release regression suite.

Four self-contained review exports are generated by
`../tools/build_v15_2_standalone.mjs` under `../output/v15_2/standalone/`.
They are derived artifacts; edit and test the source here before regenerating
them.

The optional empty D1/R2 declarations in `.openai/hosting.json` are inherited
project metadata, not deployment authorization. No database, account, or sign-in
flow is required for this local reader.

## Authorization boundary

Do not deploy, publish, add analytics, enable authentication, create a database,
or change hosting/permissions without a new explicit instruction for that exact
action.
