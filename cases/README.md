# Case workspace

Cases are bounded illustrations. They do not validate the framework or grant
permission to scrape, advise, deploy, or act. V16 requires a serious Signal
Foundry translation and at least two domain-neutral examples.

## Cases

- [signal-foundry/](signal-foundry/) — serious transcript-first translation,
  explicitly read-only and not validation.
- [general-research/](general-research/) — choosing whether to add a second
  weekly session, using invented fixture records.
- [product-and-process/](product-and-process/) — deciding whether to change an
  intake process, using invented fixture records.

Every case states its evidence boundary, permission boundary, stop logic, and
residual risks. None is a runtime report, empirical result, or product claim.
