# Project-use starter

Status: **optional internal agent/operator repository-local wayfinding; not a
portable packet, adoption or conformance standard, mandatory route, or proof
of transfer**

Use this page when a materially different project needs a first bridge into
v16. Its only job is to map local context to existing records. The Quickstart,
decision brief, implementation choices, and templates remain canonical.

## 1. Gate ordinary work first

Ask:

> Does the task require any material claim judgment, comparison, selection or
> withholding, permission resolution, memory reuse, new acquisition,
> externally consequential influence, or a separate human action gate, rather
> than only a reversible transformation of user-supplied material?

Ordinary is valid only for a reversible transformation of user-supplied
material that requires no material claim judgment, comparison, selection or
withholding, permission resolution, memory reuse, new acquisition, externally
consequential influence, or a separate human action gate.

**NO:** return only the four fields in
`framework/templates/ORDINARY_RECORD.md`: supplied scope, material
assumptions, unchecked boundaries, and output. That record is terminal. Do not
create project, evidence, family, route, stop, learning, outcome, or influence
records. Stage 0 grants no external-action authority; externally consequential
action remains with an explicitly authorized human.

**YES:** fill the routing block below, then use the smallest existing layered
route. A single disqualifier is enough. Supplied material is not automatically
ordinary when judgment, selection, permission, or consequence remains.

## 2. Map local context to existing records

The block is a routing summary, not a second receipt. Complete the canonical
useful-answer, abstention/escalation, operation-level permission, and level-fit
fields in the referenced records before execution.

| Settle locally | Existing record | If unresolved |
| --- | --- | --- |
| Question, use, audience, consequence, reversibility, owner, reviewer, deadline, human action boundary | `framework/templates/DECISION_BRIEF.md` | `CLARIFY`, `HOLD`, or `ESCALATE`; a recommendation is not an action |
| Allowed read/acquire/transform/retain/disclose/act operations | Decision brief permission envelope | Keep the operation blocked with its reason and resume condition; access is not permission |
| Default path, expected perspectives/fields/periods, baseline, cost, privacy, latency, no-action boundary | Decision brief plus `framework/templates/ACQUISITION_RECEIPT.md` | Stop or narrow; do not manufacture motion or absence |
| Candidates, pointers, comparison, and challenge | `framework/templates/EVIDENCE_REGISTER.md`, `framework/templates/COMPARISON_MATRIX.md`, `framework/templates/DISCONFIRMATION_LOG.md` | Keep unresolved material out of influence; no placeholder work |
| Selected/withheld material, memory, and later outcome | `framework/templates/INFLUENCE_RECEIPT.md`, `framework/templates/MEMORY_RECORD.md`, `framework/templates/OUTCOME_REVIEW.md` | Keep unknown, unauthorized, stale, or superseded material from influence |

```text
PROJECT CONTEXT (fill only after Stage 0 = YES)
project:
decision_question:
intended_use_and_audience:
consequence_and_reversibility:
decision_owner_and_reviewer:
human_action_boundary:

cost_and_no_action_boundary:

```

`permission_scope_and_state` is a pointer only. Before execution, complete
separate rows for read, acquire, transform, retain/reuse, disclose, and act in
the decision brief or decision receipt. Use only `AUTHORIZED`, `UNKNOWN`,
`NOT_AUTHORIZED`, or `REVOKED`, with a reason and resume condition.

For the current single-global-permission receipt, a blocked state leaves
evidence, baseline, comparison, disconfirmation, memory, and influence empty;
records memory as `NOT_USED`; and cannot acquire, disclose, reuse, or act
through the blocked operation.

## 3. Choose the smallest existing route

- `LIGHTWEIGHT`: bounded, reversible layered work with only the minimum brief,
  comparison/challenge, and influence record that can change the decision.
- `MODERATE`: high consequence or high uncertainty without the complete
  Advanced conjunction; use stable IDs, versioning, correction, or typed
  relationships only when they earn their cost.
- `ADVANCED`: only when consequence is high, uncertainty is high, and
  substantial capacity is separately approved.

A budget records capacity and constraint; it cannot independently justify
advanced machinery. The six-family map is orientation, not a completion
checklist.
Consult `framework/SIX_FAMILIES.md` and use only a family whose question can
change this decision; otherwise record one concise reason and create no
placeholder artifact.

Continue with `framework/agent-playbook/QUICKSTART.md`. Use
`framework/agent-playbook/PREFLIGHT_CHECKLIST.md` for status evidence and
`framework/IMPLEMENTATION_CHOICES.md` for the complete fit and stopping rules.
Open only the records selected by that route.

## 4. Fail closed and stop cleanly

- Missing or unclear authority is not permission; missing baseline is not
  motion or absence.
- A dangling evidence, comparison, disconfirmation, influence, or memory link
  stays out of the answer.
- Peripheral is a candidate to inspect; recurrence is not independent support;
  provenance is not correctness.
- External action remains with the explicitly authorized human.
- This page is not self-contained. If a referenced canonical file is absent,
  request it rather than infer its contents.
- This adapter does not establish transfer, ease, compliance, answer quality,
  or framework effectiveness.
