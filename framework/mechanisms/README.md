# Mechanism index

The canonical cross-family mechanism specification is
framework/MECHANISMS.md. This directory is reserved for future focused
mechanism cards; the v16 first wave keeps the cards consolidated so the
public six-family map remains easy to inspect.

Current mechanisms:

- decision brief and permission envelope;
- bounded acquisition and capture receipts;
- evidence spine;
- typed comparison and relationship record;
- disconfirmation and uncertainty review;
- bounded route, cost, and stop policy;
- context packet and influence receipt;
- human disposition and escalation;
- versioned memory and outcome review.

These mechanisms support all six families. They are not a seventh family and
do not make one technical stack mandatory.
