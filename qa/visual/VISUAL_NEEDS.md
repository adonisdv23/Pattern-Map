## Generation gate

Bitmap generation stays closed unless a later site review identifies a
specific comprehension need that code-native treatment and existing historical
assets cannot meet. Before any such request:

1. append the need, audience, intended location, accessibility alternative,
   and reason a bitmap is materially better;
2. confirm the action remains within the owner-authorized local-review scope;
3. create and inspect the required candidate set under
   `assets/generated-candidates/`; and
4. record every candidate and derivative in `assets/IMAGE_USE_LEDGER.md` as
   used, unused, or archived with a reason.

The presence of this file does not itself authorize generation. It records the
current decision that no generated bitmap is needed.
