## Reproducing this sweep

1. `cd site && npm run build && node serve.mjs`
2. Copy `qa/interaction/layout-probe.js`, `enhancement-probe.js`, and
   `layout-sweep-driver.js` into `site/dist/assets/`, and add a module script tag
   for the driver to each generated page. These are local instruments; they are
   never part of a committed build.
3. Set the browser viewport, then run `patternMapSweep.start({...})` per the
   driver's own usage note, collecting results at a local endpoint.
4. Rebuild with `npm run build` to discard the injection before committing.
